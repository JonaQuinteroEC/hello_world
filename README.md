Primeros pasos para manejar correctamente repositorios

👣 New Proyect/ Versin Control / Git / Repository URL

🗂️ Se le puede dar el directorio donde se clonará el repositorio

Pasos para realizar cambios y confirmar (commit) desde la consola:

git add README / git add = marca el archivo para el commit (equivale a "Staged") 
git commit-m "commit desde la consola" / commit -m = guarda el cambio con un mensaje

Sincronizar con Github
git pull = trae cambios remotos antes de subir los tuyos ·
git push = sube tus commits locales a GitHub
