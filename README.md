##Primeros pasos para manejar correctamente repositorios

👣 New Proyect/ Versin Control / Git / Repository URL

🗂️ Se le puede dar el directorio donde se clonará el repositorio

1)  Pasos para realizar cambios y confirmar (commit) manualmente:

En la pestaña Git (panel superior derecho): marca la casilla Staged, click en Commit, escribe un mensaje, y click en Commit otra vez.

Click en el botón azul Pull primero (por hábito, aunque no haya cambios), y luego en el botón verde Push para enviar tus commits a GitHub.

2)  Pasos para realizar cambios y confirmar (commit) desde la consola:

git add README / git add = marca el archivo para el commit (equivale a "Staged") git commit-m "commit desde la consola" / commit -m = guarda el cambio con un mensaje

Sincronizar con Github git pull = trae cambios remotos antes de subir los tuyos · git push = sube tus commits locales a GitHub
